Implement reconcile(csv_text) using standard library only. Input is CSV text with exact ordered header id,account,amount. Return {"posted": unique accepted IDs count, "balances": dict of account to integer cents sorted lexicographically by account}. Fields id/account are strings trimmed of leading/trailing whitespace, nonempty after trimming; preserve Unicode and internal spaces. Amount is trimmed ASCII decimal matching -?[0-9]+(\.[0-9]{1,2})?; accepts zero/negative zero; no plus, exponent, underscores, NaN/inf, or non-ASCII digits. Compute exact integer cents without float. Normalize duplicate ID with same account and amount as one posted record; conflicting duplicate raises ValueError, as does malformed CSV, incorrect/missing/extra columns, non-text input, invalid fields or header. Support proper quoted CSV commas, escaped quotes, embedded newlines, CRLF, and an optional leading UTF-8 BOM. Empty input invalid; header-only valid with posted=0 balances={}. Blank physical rows after header are ignored (CSV empty row only); whitespace field rows invalid. Result includes accounts whose balance is zero. Never return partial output on any invalid record. At least 10000 rows must work. Only app.py writable; tests/SPEC protected.
