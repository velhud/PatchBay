Implement a persistent SQLite money ledger and deterministic report. Ledger(path) creates schema. Methods: post(key,account,amount) returns bool (True inserted, False exact replay); balance(account) int; rows() list of dict {key,account,amount} sorted key; close(). Nonempty keys/accounts must be strings (whitespace-only invalid), amount must be int excluding bool and nonzero. Preserve Unicode exactly. Validate before write. Duplicate key with changed account/amount raises ValueError and keeps state; exact replay False. Persistence and separate simultaneous connections must work. summarize(rows) returns a dict mapping accounts to signed sum, sorted by account insertion order, includes zero balances, never mutates input; invalid rows (same validation incl key) ValueError, bool amount rejected. Duplicate keys exact replay counted once, conflicting duplicates ValueError. Empty input {}. No third party dependencies. Two implementations can be written independently from this contract.
