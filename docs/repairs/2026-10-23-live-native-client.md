## Repair exposed by final reconciliation

The manager tried to send a shared-checkout verifier's detailed context to an
existing read-only reviewer. Peer context incorrectly treated every writable
workspace as an isolated candidate. Shared-write workers have no isolated
delivery baseline, so the normal start/follow-up path raised an internal error
before admitting a turn.

Detailed shared-write handoffs now retain the worker's advisory report and state
that no isolated candidate or attributable patch is available. They do not
capture unrelated base-checkout changes, manufacture a baseline, create review
targets, or bind source acceptance. Isolated workers retain their existing exact
snapshot, lease, review and integration checks. Six joined regressions reproduce
start/follow-up with each detailed context level; the exact pre-repair defining
method fails all six with the observed missing-baseline error.
